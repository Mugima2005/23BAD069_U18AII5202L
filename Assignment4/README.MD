# 🚦 Traffic Accident Data Visualization (R)

## 📌 Objective
To apply effective **visual encoding principles** for meaningful data communication.

## 🏙️ Scenario
A city traffic department analyzes accident data to identify **high-risk zones** and **accident severity patterns**.

---

## ✅ Visual Encoding Used
- **Severity → Color Gradient**
- **Accident Frequency → Point Size**
- **Accident Type → Shape**

---

## 📂 Dataset Columns
- Accident_ID  
- Location  
- Date  
- Time  
- Accident_Type  
- Severity  
- Vehicles_Involved  
- Casualties  

Dataset Name in RStudio: **Traffic_accidents**

---
