# Assignment 1 - Academic Performance Analysis (R)

## Objective
To design charts to analyze and compare internal assessment performance of first-year students across five subjects.

## Dataset Columns
Student_ID, Department, Semester, Subject, Internal_Test1, Internal_Test2, Assignment_Marks, Attendance_Percentage, Final_Grade

## Tools Used
- RStudio
- ggplot2, dplyr, tidyr

## Charts Generated
1. Bar Chart: Subject-wise average marks  
2. Line Chart: Performance trend across internal tests  
3. Pie Chart: Grade distribution

## Files
- `assignment1.R` : R script
- `1.student_performance.xlsx` : Dataset
- `Figures/` : Output plots (SUBJECT.png, PERFORMANCE.png, GRADE.png)
